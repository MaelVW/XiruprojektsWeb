🎬 Studio

Diese Website

Kein Framework, kein Server, keine Cloud. Xiruprojekts ist reines HTML, CSS und JavaScript – und alles, was du hier sammelst, bleibt in deinem Browser.

Aufbau

  • assets/js/site.js – das Register: alle Seiten, Inseln, Kristalle, Module
  • assets/js/core.js – Konto, Speicher, Erfahrung, Kristalle, Navigation
  • assets/js/ai.js – KI-Dienste & Offline-Modus (einziger Netzwerkzugriff)
  • assets/css/main.css + Themes – Design pro Bereich
  • hardware/ · arcade/ · ki/ · mixer/ · werkzeuge/ · studio/ – die Inseln
  • geheim/ – …

Grundsätze

  • 🔒 Deine Daten bleiben bei dir: Spielstände liegen im Browser (localStorage), nie auf einem Server.
  • 🚫 Keine Drittanbieter-Tracker oder fremden Schriften; nur dezente, schliessbare Eigenwerbung für Xiru-Spiele.
  • 📴 Funktioniert offline – sogar direkt von der Festplatte geöffnet.
  • 🧩 Ohne Build-Schritt: Jede Seite ist eine HTML-Datei, die man lesen kann.
  • 🕵 Geheimnisse überall – wer genau hinschaut, findet mehr.
