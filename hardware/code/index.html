So funktioniert's

1 · Lernen

Jede Sprache hat einen Kurs aus kurzen Lektionen: Erklärung, Beispielcode zum Kopieren und ein Mini-Quiz. Bei HTML, CSS und JavaScript kannst du den Code direkt bearbeiten und siehst das Ergebnis live.

2 · Nachschlagen

Im Reiter „Cheat-Sheet“ stehen alle Begriffe als Tabelle – Begriff, Code-Beispiel, Beschreibung – mit Suche. Ideal neben dem Editor.

3 · Mitnehmen

Ein Klick erzeugt das Cheat-Sheet als echte Word-Datei (.docx) – direkt in deinem Browser, nichts wird hochgeladen. Ausdrucken, ergänzen, in die Schule mitnehmen.
