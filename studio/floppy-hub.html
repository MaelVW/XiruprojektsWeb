Floppy Hub

Eine echte Diskette ins Laufwerk – und dein Spiel startet. Floppy Hub macht aus einem Stapel alter Disketten eine Spielebibliothek zum Anfassen.

So funktioniert's

  1. Diskette bespielen – Der Diskettenbespieler schreibt eine kleine game.txt auf die Diskette: Name, Cover und welcher Befehl das Spiel startet.
  2. Einlegen – Floppy Hub merkt, wenn eine Diskette eingelegt wird, und liest die Datei.
  3. Bestätigen – Bevor etwas gestartet wird, fragt Floppy Hub nach. Sicherheit zuerst.
  4. Spielen – Das Spiel startet. Diskette raus, nächste rein.

Technik

💻 PowerShell

Komplett in PowerShell geschrieben – Cmdlets wie Get-Content, Test-Path und Read-Host machen die Arbeit.

📟 Retro-Menü

Ein Menü im Stil alter DOS-Programme, steuerbar mit der Tastatur.

🔒 Nachfragen

Nichts startet ohne deine Bestätigung – eine Diskette kann niemals heimlich etwas ausführen.
