Nur für Xiru-Admins

Admin

Moderation auf dem Xiru-Server: Konten ansehen, sperren und entsperren, Admin-Konten anlegen. Jede Aktion prüft der Server selbst – ohne Admin-Rolle geht hier nichts.

Anmelden

Server: (Einstellungen → Online). Den ersten Admin legt der Superuser in der PocketBase-Oberfläche fest: users → Konto → role = admin.

Konten

KontoStand (geprüft)StatusAktionen

Entsperren: Sperre weg, der Server prüft weiter gegen den letzten geprüften Stand (wer wirklich geschummelt hat, wird beim nächsten Abgleich wieder gesperrt). Entsperren + Stand annehmen: der nächste Spielstand gilt als neuer Ausgangspunkt (nur grobe Obergrenzen) – für Irrtümer.

Admin-Konto anlegen

Admin-Konten werden vom Anti-Cheat nicht geprüft, zählen aber in keiner Rangliste – gedacht zum Testen. Danach auf der Website mit diesem Namen anmelden („Vom Server holen“) und unten alles freischalten.

Admin-Spielkonto ausstatten

Wie das Testkonto: alle Module, Inseln und Baupläne, jedes Mech-Teil mythisch, Level 99, viel Material und Taler, auf Mnemora Arche, Besatzung, alle Orte, Strassen, Gehäuse und Steckkarten. Kristalle bleiben zum Finden. Geht nur für das Admin-Konto, mit dem du hier angemeldet bist.
